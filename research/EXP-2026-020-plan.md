# EXP-2026-020: one long/short direction layer for every bot

Owner (2026-11-22): every bot should trade in any trend, long in uptrends and short in
downtrends, as shared logic rather than per-bot patches.

## Audit (code at main 9fd7662)

| Bot | Direction logic | Both ways? |
| --- | --- | --- |
| perps main (4h) | `perps/signals.py` `tsmom_30d`: long if price > 30 days ago, else short; always in the market | Yes |
| perps degen (1h sweep) | same `tsmom_30d`, read from 4h candles (ADR-040) | Yes |
| spot | `strategies/sma_trend.py`: buys only on the 4h bar where SMA20 crosses above SMA50; sells when below | No, long only |
| regime layer | `regimes/null_classifier.py` returns "unknown"; nothing reads trend state | Not built |

Spot is long-only by a non-negotiable repo rule (CLAUDE.md: "Spot code stays long-only with
no leverage or margin"; shorting exists only in paper `trader/perps/`). So a spot short side
must run through the perps package.

Perps had no new trades from Nov 15 to 22 because the 30-day trend pointed down on BTC, ETH
and SOL for all of November (0 flips from Nov 1 to 21 in this data), so the bots held
shorts. That is the stance rule working, not a one-sided rule.

## Test

`research/run_exp020.py`: BTC/ETH/SOL 4h Binance spot candles 2020-01..2026-11-21, 1x per
coin, equal weight, 7 bps fee a side, Jupiter borrow on both sides, a hard stop 2 typical
daily moves away on every trade, next-UTC-day wait after a stop. Picked on 2020-2023,
checked on 2024-2026. Rules: tsmom30, SMA 50/200, SMA 20/50, and two regime filters that go
flat in ranges (price vs SMA200 + 30-day momentum, with or without SMA200 slope); each run
long+short, long only, short only.

## Results (see EXP-2026-020-results.txt)

- Adding shorts helps in bear markets and costs in bull markets. 2022: tsmom30 long-only
  -16%, long+short +88%. Last 60 days: long-only -12%, long+short +19%.
- Over full cycles, shorts lowered tsmom30's return and Sharpe in both periods (holdout
  long+short -3.1%/yr vs long-only +7.3%/yr).
- SMA 50/200 both ways was the best long+short rule out of sample: +23.9%/yr, Sharpe 0.67,
  max DD 48% (long-only +19.5%/yr, DD 35%). Its short side made +25% in the holdout but lost
  slightly (-9%) in development. EXP-2026-019 (Coinbase, 3y, last 180d held out) found the
  same pattern.
- Regime filters that sit flat in ranges did not beat the plain rules in either period.
- Borrow cost decides the short side: at the old 0.01%/h every long+short variant lost in
  the holdout.

Caveats: spot prices stand in for perps, funding is not modeled, 1x only (the bots run
leverage), and past results do not guarantee future ones.
